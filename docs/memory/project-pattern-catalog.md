**Fact:** Reusable code stays in its source project; a one-line pointer goes in the registry's
`PATTERNS.md` at each retro/review; at the **second** use it is promoted to a capability-scaffold
skill. Encoded in the `crystallize` skill, Step 5.

**Why:** No harvester tool — "is this reusable?" is judgment, not mechanism. "Project finished" is not
a trigger, because projects never finish. And never generalise from one example: the second consumer
is what reveals the seams.

**Authority:** AGENTS 7, skills/crystallize
